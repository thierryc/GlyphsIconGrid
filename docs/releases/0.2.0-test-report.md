## Native live geometry

The reporter's real loaded instance was queried against the real Glyphs metric
stores in both apps. The same results were then checked visually in Edit view.

| Check | Regular | Bold |
| --- | --- | --- |
| Native H stem | 84 | 135 |
| Native Mid Height | 353 | 353 |
| Construction center | `(500, 353)` | `(500, 353)` |
| Canvas bounds | `(0, -147, 1000, 853)` | `(0, -147, 1000, 853)` |
| Live/keyline diameter | 875 | 875 |
| Inner rings / spokes / keylines | 2 / 8 / 4 | 2 / 8 / 4 |

An empty Mid Height store exposed a Glyphs API behavior that the original unit
fixture did not model: current Glyphs builds bridge the empty position as
`0.0`. The release candidate was corrected to treat non-positive Mid Height
positions as unavailable. Fresh disposable fixtures with empty Mid Height
stores then resolved to center `(500, 350)`, baseline offset `150`, and canvas
bounds `(0, -150, 1000, 850)` in both Glyphs versions.

The live mutation matrix also passed in both apps:

- Mid Height overshoot `27` did not change the center.
- A filtered Mid Height fell back to `y=350`.
- Explicit `IconGrid.baselineOffset = 125` remained authoritative.
- All nine origins produced valid fixed 1000-unit canvases.
- `odd` centered a cell on both axes; `even` put lines on both axes.
- Advance widths 600, 1000, and 1400 remained horizontally centered without
  stretching the canvas.
- Outline and width signatures matched exactly after the live matrix was
  restored.

## UI and interaction verification

- **View → Show Icon Grid** was present and active in Glyphs 3.5 and Glyphs 4.
- Select, Draw, Circle/Primitives, and Annotation showed the appropriate grid.
- Text, Hand, Zoom, and Measurement suppressed it as specified.
- The expanded field, rings, spokes, keylines, metric guides, and Mid Height
  placement redrew cleanly while switching masters and tools.
- The injected native-adapter suite exercised Draw, Pencil, Rectangle, Circle,
  node-move, lasso, Annotation, hover, scale, and 64-node interaction limits.
- Final Macro Panel inspection showed no `IconGrid:` warnings or exceptions.
