# GlyphsIconGrid 0.1.0

The first public release adds a weight-aware construction grid to Glyphs 3.5 and Glyphs 4.

- Inherit each master’s H stem for both square-cell size and circular spacing.
- Start new 1000-UPM icon stems at 84 units on Regular and 135 units on Bold, then measure and optically correct the design.
- Center the construction system vertically halfway between the baseline and cap height.
- Fit the live/keyline diameter to `capHeight / 0.8`, so the landscape keyline spans exactly from baseline to cap height.
- Cover more of the Edit view with at least four overflow cells per side.
- Keep the radial construction focused with at most two inner circles plus the outer keyline.
- Use the cell-centered `odd` grid by default, or opt into line-centered `even` mode.
- Draw square grids, concentric circles, spokes, live-area frames, and common icon keylines behind the active glyph.
- See strict non-snapping alignment feedback while drawing or moving nodes.
- Inspect and change settings safely through the included Glyphs MCP skill.
- Install the bundled agent skill without a repository checkout or Python by double-clicking the included Mac installer.

See the [user guide](https://github.com/thierryc/GlyphsIconGrid/blob/v0.1.0/docs/USER_GUIDE.md) and [complete parameter reference](https://github.com/thierryc/GlyphsIconGrid/blob/v0.1.0/docs/PARAMETERS.md).
